# DIREITOSHUMANOSDIGITAIS
Projeto sobre Direitos Humanos Digitais com foco em privacidade, inclusão digital, liberdade de expressão e combate ao discurso de ódio. Desenvolvido com dashboard dinâmico, banco de dados e ferramenta de denúncias digitais, alinhado à LGPD, Marco Civil da Internet e ao ODS 16.
