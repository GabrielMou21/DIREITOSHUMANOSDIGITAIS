# DIREITOSHUMANOSDIGITAIS
Projeto sobre Direitos Humanos Digitais com foco em privacidade, inclusão digital, liberdade de expressão e combate ao discurso de ódio. Desenvolvido com dashboard dinâmico, banco de dados e ferramenta de denúncias digitais, alinhado à LGPD, Marco Civil da Internet e ao ODS 16.

## Objetivo do Projeto

O DHDigital foi criado com foco acadêmico e extensionista para promover:

* Educação digital
* Conscientização jurídica
* Inclusão digital
* Combate à desinformação
* Proteção de dados pessoais
* Direitos humanos na internet

O projeto está alinhado ao:

* Objetivo de Desenvolvimento Sustentável 16 (ODS 16)

  * Paz
  * Justiça
  * Instituições eficazes
